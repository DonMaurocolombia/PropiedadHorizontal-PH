1. Stack Tecnológico Recomendado (C++ Moderno)
Para que tu aplicación tenga una interfaz gráfica profesional y no parezca un programa antiguo, utiliza estas herramientas:
 - Lenguaje: C++20 (ofrece manejo seguro de memoria con smart pointers, std::format, fechas con std::chrono, etc.).
 - Interfaz Gráfica (GUI): Qt 6 (Widgets o QML). Es el estándar de la industria en C++ para aplicaciones empresariales de escritorio; permite crear tablas, formularios complejos y exportar a PDF fácilmente. (Alternativa ligera: Dear ImGui + GLFW, aunque Qt es superior para sistemas administrativos).
 - Base de Datos Embebida: SQLite 3 (usando la librería wrapper SQLiteCpp). Al ser un solo archivo .db, facilita las copias de seguridad y hace que la aplicación sea 100% portable.
 - Generación de Reportes y PDF: QtPdf / QPrinter (para generar cuentas de cobro y estados financieros en PDF directamente desde plantillas HTML/CSS) o PoDoFo.
 - Cifrado y Seguridad: OpenSSL o libsodium para hashear contraseñas de los perfiles de usuario (Argon2 o bcrypt).

Perfiles de Usuarios y Auditoría: Control de acceso basado en roles (Administrador, Contador, Revisor Fiscal, Recepción/Vigilancia) y un log de auditoría que registre quién modificó o borró un registro contable.

Gestión de PQRS y Sanciones: Registro de quejas, llamados de atención, proceso de descargos (debido proceso) y aplicación de multas por incumplimiento del manual de convivencia.
Mantenimiento Preventivo y Proveedores: Cronograma de mantenimiento de ascensores, motobombas, tanques de agua y pólizas de áreas comunes (obligatorias por ley), con alertas de vencimiento.
Reserva de Zonas Comunes: Calendario para reservar salón social, BBQ o zonas húmedas, generando automáticamente el cobro de alquiler o depósito en la cuenta del residente.

4. Ejemplo de Lógica Central en C++ (Liquidación y Base de Datos)
Aquí tienes una base de cómo modelar el motor de liquidación de cuentas de cobro respetando los coeficientes y evitando errores de redondeo financiero (usando int64_t en centavos o double controlado):
cpp
#include <iostream>
#include <vector>
#include <string>
#include <cmath>
#include <iomanip>

struct UnidadPrivada {
    int id;
    std::string nomenclatura; // Ej: "Torre 1 - Apto 302"
    double coeficiente;       // Ej: 0.0125 (equivale al 1.25%)
    long long saldoAnterior;  // En pesos COP
};

struct CuentaCobro {
    int unidadId;
    std::string periodo;      // Ej: "2026-11"
    long long cuotaOrdinaria;
    long long interesMora;
    long long totalPagar;
};

class MotorFacturacion {
public:
    // Calcula la cuenta de cobro mensual según el presupuesto mensual de la copropiedad
    static CuentaCobro liquidarMes(const UnidadPrivada& unidad, 
                                   long long presupuestoMensualTotal, 
                                   double tasaMoraMensual,
                                   const std::string& periodo) {
        CuentaCobro cuenta;
        cuenta.unidadId = unidad.id;
        cuenta.periodo = periodo;

        // 1. Cuota ordinaria = Presupuesto Total * Coeficiente (redondeado al peso)
        cuenta.cuotaOrdinaria = std::llround(presupuestoMensualTotal * unidad.coeficiente);

        // 2. Interés de mora sobre capital vencido (si tiene saldo anterior)
        if (unidad.saldoAnterior > 0) {
            cuenta.interesMora = std::llround(unidad.saldoAnterior * tasaMoraMensual);
        } else {
            cuenta.interesMora = 0;
        }

        // 3. Total a pagar
        cuenta.totalPagar = unidad.saldoAnterior + cuenta.cuotaOrdinaria + cuenta.interesMora;
        return cuenta;
    }
};

int main() {
    // Ejemplo: Presupuesto mensual del edificio = $25.000.000 COP
    long long presupuestoMensual = 25000000;
    double tasaMora = 0.018; // 1.8% mensual

    UnidadPrivada apto101{1, "Torre A - 101", 0.0145, 350000}; // Debe $350.000
    CuentaCobro cobro = MotorFacturacion::liquidarMes(apto101, presupuestoMensual, tasaMora, "2026-11");

    std::cout << "Unidad: " << apto101.nomenclatura << "\n"
              << "Cuota Ordinaria: $" << cobro.cuotaOrdinaria << "\n"
              << "Interes Mora:    $" << cobro.interesMora << "\n"
              << "Total a Pagar:   $" << cobro.totalPagar << "\n";

    return 0;
}
Usa el código con precaución.

### Puntos Clave de este Diseño para tu Código C++

1. **Trazabilidad Contable (Partida Doble):** Cada vez que tu programa genere un lote de cuentas de cobro o guarde un recibo de caja, creará una fila en `comprobantes_contables` y sus respectivas líneas en `movimientos_contables`. En tu clase C++ `AccountingEngine`, valida siempre antes del `COMMIT` que `SUM(debito) == SUM(credito)`.
2. **Prelación de Pagos (Código Civil Colombiano):** La tabla `recibos_caja_aplicacion` se conecta directamente con `cuentas_cobro_detalle` (y no solo con el encabezado de la factura). Esto permite que cuando un propietario haga un abono parcial, tu código en C++ liquide primero los detalles de concepto `'MORA'` y luego los de `'CUOTA_ORD'` más antiguos.
3. **Ejecución Presupuestal en Tiempo Real:** Como `presupuesto_rubros` apunta a `cuenta_codigo` del PUC, puedes obtener la ejecución presupuestal en cualquier momento con una simple consulta `SUM(debito - credito)` sobre `movimientos_contables` filtrada por el año y las cuentas `51%` (Gastos).
4. **Control de Parqueaderos y Bodegas:** Al tener el campo `tipo_tenencia`, puedes separar fácilmente los parqueaderos que tienen matrícula inmobiliaria propia (y pagan cuota por coeficiente) de los bienes comunes asignados por alquiler (que generan un cobro fijo mensual en `cuentas_cobro_detalle`).

req.movimientos = {

2. Fórmula de Conversión Legal en Colombia (EA a Tasa Mensual)

La Superintendencia Financiera publica la tasa en términos Efectivos Anuales (EA).
Para evitar cobrar por encima del tope de usura, tu código en C++ puede convertir automáticamente 
la tasa EA a Tasa Mensual Vencida (TMV) mediante la fórmula financiera exacta:

\(TMV=(1+EA)^{\frac{1}{12}}-1\)
En C++ (usando <cmath>):
cpp
// Ejemplo: EA = 0.2781 (27.81% Efectivo Anual)
double convertirEAaMensual(double tasaEA) {
    return std::pow(1.0 + tasaEA, 1.0 / 12.0) - 1.0;
}


3. Ajuste en BillingEngine::generarFacturacionMensual()

Al generar la facturación de un periodo específico (por ejemplo, "2026-11"), el motor buscará primero la tasa registrada para ese mes exacto en tasas_mora_historial y, si no se ha registrado ese mes, usará la tasa por defecto de copropiedad_config:
cpp
// En BillingEngine::generarFacturacionMensual(...)
double tasaMoraMensual = 0.018;

// 1. Buscar si existe tasa histórica específica para el periodo que se está liquidando
SQLite::Statement histStmt(db, R"(
    SELECT tasa_mensual_aplicada
    FROM tasas_mora_historial
    WHERE periodo = ?
)");
histStmt.bind(1, periodo);

if (histStmt.executeStep()) {
    tasaMoraMensual = histStmt.getColumn(0).getDouble();
} else {
    // 2. Fallback: tomar la tasa general configurada en copropiedad_config
    SQLite::Statement cfgStmt(db, "SELECT tasa_mora_mensual FROM copropiedad_config WHERE id = 1");
    if (cfgStmt.executeStep()) {
        tasaMoraMensual = cfgStmt.getColumn(0).getDouble();
    }
}

• Reliquidaciones exactas: Si necesitas anular y volver a generar un mes anterior, el motor tomará automáticamente la tasa histórica correspondiente a ese periodo y no la tasa actual.
