# CATALOGO DE CUENTAS CONTABLES PARA COPROPIEDADES - PUCC

La codificación del Catálogo de Cuentas está estructurado sobre la base de los siguientes niveles.

| **NIVEL** | **DESCRIPCIÓN** |
|---|---|
| **Clase** | El primer dígito. |
| **Grupo** | Los dos primeros dígitos. |
| **Cuenta** | Los cuatros primeros dígitos. |
| **Subcuenta** | Los seis primeros dígitos. |


Las clases que identifica el primer dígito son:

| **CLASE** | **DESCRIPCIÓN** |
|---|---|
| **1** | Activo |
| **2** | Pasivo |
| **3** | Patrimonio |
| **4** | Ingresos |
| **5** | Gasto |
| **8** | Cuentas de Orden Deudoras |
| **9** | Cuentas de Orden Acreedoras |

Las clases 1, 2 y 3 comprenden las cuentas que conforman el Estado de Situación Financiera (antes Balance General), las clases 4 y 5 corresponden a las cuentas del Estado de Pérdidas o Ganancias, o Estado de Resultados, y las clases 8 y 9 detallan las Cuentas de Orden.

# Auxiliares

Adicionalmente a las subcuentas indicadas en el catálogo presentado, se podrían utilizar auxiliares que se requieran de acuerdo con las necesidades de la copropiedad, para lo cual bastará con que se incorporen a partir del séptimo digito.

Insisto en que este es un simple modelo gruía, de libre distribución, adopción y utilización, cada copropiedad puede ajustarlo a la necesidad propia o ya existente.
